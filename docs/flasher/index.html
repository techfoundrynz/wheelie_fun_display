BEFORE YOU CONNECT

A few simple steps.

  1. 1

    Choose the exact model

    Use the display name printed on your board. The installer checks the connected chip family.

  2. 2

    Connect over USB

    Use a data cable and close any serial monitor. Select the display’s USB port when your browser asks.

  3. 3

    Install, then restart

    Keep the display powered until installation finishes. Use its touchscreen to connect Wi-Fi and your bike afterward.

Already running Wheelie Fun Display?

Use Settings → Firmware updates for normal updates. A complete USB installation replaces the flash layout and can reset saved settings.

Port missing? Hold BOOT, tap RESET, then release BOOT. See USB installation instructions for board setup and terminal flashing.

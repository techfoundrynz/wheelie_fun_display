# Display cases and mounts

Native Fusion archives and STEP exports for Wheelie Fun Display cases, cable grommets and mounting parts, grouped by display module.

- [Waveshare ESP32-S3 Touch AMOLED 2.06 casing and handlebar clamp](waveshare-206/README.md)

Part files contain one custom component each, without display reference geometry, handlebars or standard fasteners. Dimensions are in millimetres. Keep each module's exports and assembly notes together when adding another design.

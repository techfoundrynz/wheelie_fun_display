# Display cases and mounts

Editable Fusion design and STEP exports for Wheelie Fun Display cases, cable grommets and mounting parts, grouped by display module.

- [Waveshare ESP32-S3 Touch AMOLED 2.06 casing and handlebar clamp](waveshare-206/README.md)
- [GUITION 4.3-inch case and handlebar mount](guition-43/README.md)

Download the [shared editable Fusion assembly](wheelie-fun-display-mounts.f3d) for both display families. The source includes Waveshare landscape and portrait assemblies, a GUITION landscape assembly, shared fasteners and reference geometry. Individual folders contain one-solid STEP exports and assembly instructions; display references, cable jackets, handlebars and standard fasteners are excluded from those manufacturing files. Dimensions are in millimetres.

Exported from saved Fusion version 17 of **Wheelie Fun Display - Waveshare 2.06**, with no unsaved changes, on 8 November 2026. The document's historical name is retained in Fusion; the archive filename reflects its shared contents. Re-export the full source and refresh both guides when a shared part changes.
